# Unidrain × Villa Sjövik — underlag

Publiceras på https://villasjovik.github.io/unidrain-presentation/ · `noindex`.

Byggd efter mötet 2026-08-18, där Johannes Walter bad om att få se hur
förvandlingen i badrummet skulle se ut innan han kan bedöma upplägg och budget.

**Detta är inte en pitch.** Inga priser, inga paket, ingen CTA. Två nivåer och
tre frågor tillbaka.

## Struktur

| Sektion | Innehåll |
|---|---|
| Hero | Före/efter-pendel som svepar av sig själv, mätt med måttlinjer |
| Statement | Kopplar tillbaka till Johannes eget förslag på mötet |
| 01 Uppfräschningen | Reframe Collection i svart. Inget ingrepp i golvet. |
| 02 Hela steget | GlassLine Black. Med ShowerLine-förutsättningen uttalad. |
| 03 Tre frågor | Produktval · duschväggens roll · vad de hellre vill lyfta |

## Designvärld

Riktning C (Fallet) med riktning A:s (Snittet) mätspråk — vald av Lucas ur tre
komposer. Rinnan i borstat stål löper genom hela sidan som bärande grafiskt
element; innehållet grenar av från den. Måttlinjer och specifikationstabeller
lånade ur den arkitektoniska detaljritningen. Familjen Grotesk (Letters from
Sweden). Enda accent är det kalla vattenblå som måttlinjerna ritas i.

Alternativen ligger kvar i `_comps/` (gitignorerad).
